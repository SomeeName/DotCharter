# DotCharter.Presentation Agent Guide

The UI rewrite's presentation layer: screen CONTRACTS, screen view models and
the seams between screens of one area. The design is
[docs/agents/ui/target-architecture.md](../docs/agents/ui/target-architecture.md)
— read §§ 2–4 before adding anything here; § 3.5 is the worked example (Settings).

## Rules, and what enforces each

- Home's song actions carry `HomeHero` / `ProgressItem` song keys and recorded
  arrangement identities through `IShellDestinations.PlaySongAsync`. `Go(Play)`
  is the generic library destination, not a request to resume a song.

- References Core, Localization, Services and CommunityToolkit.Mvvm only — never
  an assembly whose name starts with `Avalonia`, `Dock`, `SkiaSharp` or
  `JuceSharp`. Services brings Avalonia and JuceSharp in TRANSITIVELY, so a
  `using Avalonia` compiles; `Infrastructure/AssemblyLayeringTests` reads the
  emitted references and fails the gate.
- No file, process, network, SQLite or `GetFolderPath` access, and no
  `JuceAudioPlaybackService` / `IAudioPlaybackService`: the banned-API analyzer
  (`DotCharterBannedApis` + `DotCharterBannedPresentationApis` in the csproj,
  lists in the root `BannedSymbols*.txt`) makes each an RS0030 build error. No
  `#pragma` around it — `Presentation/PresentationSourceRulesTests` counts them.
  Take a focused audio seam instead (`IPlaybackTransport`, `IAudioDeviceControl`,
  `IStemMixer`, `IVstChainHost`, `ILiveInputCapture` — table in
  `docs/agents/services/audio-engine.md`, pending owner approval). **RS0030 does
  not see a field or parameter TYPED as the service**, only member uses and
  `typeof`, so `UI/AudioSeamRegistrationTests` checks the types by reflection.
- ≤ 400 lines a file, ≤ 600 lines and ≤ 2 files a type, no comment that narrates
  history (a date, a version, until / used to / no longer / shipped), and ≤ 20 %
  comment lines outside `Contracts/`: `Presentation/PresentationSourceRulesTests`.
- ≤ 7 constructor parameters, and a `*ViewModel` never holds another screen's
  view model outside its own folder or `Shared/`: `Presentation/PresentationTypeRulesTests`.
