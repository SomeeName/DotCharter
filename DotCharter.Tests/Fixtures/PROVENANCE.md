# Fixture and asset provenance

Every tracked binary or data fixture in this repository has a row here: where it
came from, and under which licence. `Infrastructure/FixtureProvenanceLintTests`
fails the gate when a tracked fixture has no row, and when a row names a file
that is no longer tracked.

- The first cell is the repo-relative path in backticks. A path ending in `/`
  covers every tracked file under that folder (used where a whole generated or
  vendored set shares one origin).
- Covered: audio, images, fonts, archives, models, captures, Guitar Pro / EOF /
  MIDI / PSARC / SNG files, `.json` under `DotCharter.Tests/` or an `Assets/`
  folder or 64 KB and up, `.txt` / `.xml` under a `Fixtures/` folder, and
  `.html` / `.js` under `docs/`.
- The owner's private corpus (`TestData/`, git-ignored) is never in the repo.
- Rule for new fixtures: self-made (synthetic, generated in code, or composed for
  the project) or vendored with a licence that allows redistribution. Never a
  note-for-note transcription or a recording of a real song, album art, or an
  in-game screenshot. Song TITLES as labels are fine.
- Status `OWNER` marks an item derived from the owner's own material that needs
  a decision before the repository goes public.
